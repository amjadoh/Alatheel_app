# الأثيل 1.8.2 — حفظ الدخول واستعادة الاتصال

- تهيئة التخزين الدائم قبل تسجيل Google، مع استخدام IndexedDB والتخزين المحلي كبديل عند الحاجة.
- معالجة مسار قد يمسح الجلسة المحفوظة عند التحويل إلى تخزين غير متاح على الجهاز.
- استعادة الحساب عند إعادة فتح التطبيق، وانتظار التحقق دون عرض شاشة تسجيل الدخول أثناء استعادته.
- إعادة المحاولة عند عودة الاتصال دون حذف الجلسة بسبب فشل تحقق مؤقت.
- استمرار حد الدخول البالغ 7 أيام، والخروج اليدوي، ومنع الحساب المعطل أو الملغاة جلسته.

لا تتضمن هذه النسخة تغييرات في الحسابات أو التحصيل أو البيانات المالية.

نسخة اختبار محفوظة كمسودة؛ لا يُفعّل التحديث العام قبل التحقق من الإغلاق وإعادة الفتح على الجوال المتأثر.
