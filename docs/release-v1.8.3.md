# الأثيل 1.8.3

- تحسين حفظ تسجيل الدخول لمدة 7 أيام واستعادة الحساب بعد إغلاق التطبيق أو عودة الاتصال.
- عرض طريقة تحديث مكوّن أندرويد على الأجهزة القديمة التي تحتاجه لتشغيل التطبيق.
- استمرار تسجيل الخروج اليدوي والتحقق من الصلاحيات والحسابات المعطلة.

لا تتضمن النسخة تغييرات في الحسابات أو التحصيل أو بيانات الإسطبل.
