# مصطلحات التطبيق

تستخدم الشاشات والنماذج والكشوف والتقارير المصطلحات التالية بالمعنى نفسه:

| المصطلح | المقصود |
| --- | --- |
| التحصيل | المبالغ المستلمة فعليًا من المالك، للإيواء أو المصروفات المستحقة عليه. |
| تاريخ التحصيل | تاريخ استلام المبلغ من المالك؛ يحدد شهر التحصيل الفعلي. |
| دفعات المالك | سجل مبالغ التحصيل من مالك الخيل وتوزيعها على الاستحقاقات. |
| سداد المصروف | المبلغ الذي يدفعه الإسطبل للطبيب أو العامل أو غيرهما. |
| تاريخ سداد المصروف | تاريخ خروج المبلغ من الإسطبل؛ يحدد شهر المدفوعات الفعلية. |
| المدفوعات | إجمالي سداد المصروفات ومشتريات المخزون المسجلة، باستثناء السداد الملغى. |
| الفرق بين التحصيل والمدفوعات | التحصيل الفعلي ناقص المدفوعات الفعلية؛ لا يمثل رصيد البنك. |
| نتيجة التشغيل المقدّرة | الدخل المتوقع ناقص تكلفة الاستهلاك والتشغيل، بما فيها المصروفات غير المسددة؛ تعرض كفائض أو عجز. |
| يُسترد من المالك | مصروف يُضاف إلى حساب خيله؛ تحصيله منه وسداده لمقدم الخدمة عمليتان مستقلتان. |
| تسجيل صنف | تعريف صنف مخزون برصيد صفر. |
| شراء وإضافة | شراء مدفوع يزيد كمية الصنف نفسه ويسجل المصروف والسداد مرة واحدة. |
| تصحيح زيادة رصيد | تصحيح كمي للجرد؛ لا ينشئ مبلغ شراء. |

أسماء خيارات دفعات المالك المعتمدة: «دفع جزئي»، «دفع استحقاق الشهر»، «دفع متأخرات». لا تغيّر أسماء الحقول المخزنة أو الإجراءات عند تعديل النص الظاهر.
